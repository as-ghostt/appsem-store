Almacenamiento en Android

Datos locales, permisos y copias de seguridad de BotShow para Android.

Versión 1.0 · Actualización: 14 de noviembre de 2026

1. Tecnología de la APK

Esta aplicación es nativa de Android: no depende de cookies del navegador para sus pantallas principales. La política de cookies de BotShow web describe exclusivamente tecnologías del sitio web y no representa de forma precisa el almacenamiento de esta APK.

2. Almacenamiento local

Android guarda preferencias, perfiles, ajustes de voz, configuración de automatizaciones, historial de sesiones, estadísticas, referencias de archivos seleccionados y cachés necesarios para la aplicación. La APK usa mecanismos como SharedPreferences y almacenamiento de caché. Los archivos originales elegidos desde el sistema permanecen en la ubicación administrada por el usuario o su proveedor de archivos.

3. Copias de seguridad

La APK permite los mecanismos de copia de seguridad del sistema Android. Según la configuración del dispositivo y de Google, determinados datos pueden respaldarse o transferirse. Borrar datos de BotShow del teléfono no elimina automáticamente las copias controladas por el sistema ni los datos de cuenta almacenados remotamente.

4. Permisos y contenido enviado

La aplicación utiliza conectividad para verificar el acceso y recibir eventos LIVE. Las notificaciones, servicio en primer plano y permiso de superposición contribuyen al uso durante las transmisiones cuando esas funciones están activas. Al utilizar TTS online, se envía texto al proveedor de voz elegido; las estadísticas de sesiones del anfitrión principal pueden sincronizarse con Cloudflare.

5. Borrado y derechos

Puedes administrar permisos y almacenamiento desde Ajustes de Android. Para la eliminación de la identidad BotShow y los datos remotos consulta Eliminación de cuenta y datos o la Política de privacidad.
